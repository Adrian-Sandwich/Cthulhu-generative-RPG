# Docs index

Current, actively-maintained docs are at the top of `docs/`. Everything else is
grouped by kind.

## Current
- **DEPLOY.md** — production deploy (Fly.io + hosted LLM).
- **ABUSE_POLICY.md** — threat model, rate limiting, moderation.
- **PLAYTEST_FINDINGS.md** — playtest results and backlog.
- **TECH_DEBT.md** — known, deferred items.

## Folders
- **reference/** — Call of Cthulhu 7e rules, dice/roll mechanics, story format spec.
- **guides/** — how to play / run / use (quickstart, gameplay guide, launch, web app).
- **design/** — architecture, protocol, generative edition, changelog, model/perf notes.
- **reports/** — historical validation reports, session summaries, extraction protocol,
  and image-subsystem notes (archived, point-in-time).
